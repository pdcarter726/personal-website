What it is

A custom EEG visualizer that works with Neuropawn's Knightboard. This version is built to work in browsers and as a custom desktop application. It includes full 8 channel EEG displays and a built in simulator if no hardware is available. It has a full SSVEP suite with calibration, testing and recognition. EEG recordings can be created and exported as well.
